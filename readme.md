# 인문사회대 캠퍼스 생활 설문 결과 대시보드

이 프로젝트는 인문사회대 학생 60명을 대상으로 한 캠퍼스 생활 설문 결과를 대시보드 형태로 시각화 및 분석하는 Streamlit 애플리케이션입니다.

## 🌟 주요 기능
1. **CSV 파일 업로드 및 원본 데이터 미리보기**
   - `campus_life.csv` 업로드 기능 지원
2. **데이터 전처리 및 이상치/결측치 자동 감지**
   - 잘못된 데이터(수면/공부/스마트폰 시간 이상치, satisfaction 범위 이탈 등)를 자동으로 감지하여 분석에서 제외하고 제외 건수를 투명하게 표기
3. **학과 필터링 연동**
   - 소속 학과 선택 시 평균 학교생활 만족도 및 분석 결과 자동 실시간 업데이트
4. **트렌디한 파스텔 블루 톤 시각화**
   - **선그래프**: 학교생활 만족도와 생활 시간(공부, 수면, 스마트폰) 간의 관계
   - **히트맵**: 주요 설문 항목 간 상관관계 분석
   - **막대그래프**: 한 줄 의견 내 상위 10개 주요 등장 단어 시각화
5. **한 줄 의견 감성 키워드 분석**
   - 학과 선택에 연동된 긍정 단어 및 부정 단어 등장 횟수 산출
